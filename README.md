# Virtual Assistant Using Python

## Overview
This project is a Python-based desktop virtual assistant designed to simplify everyday computer tasks through voice commands and automated actions.

## Example commands
"open google", "tell me the time", "which day it is", "tell me about python from wikipedia", "meaning of serendipity", "play despacito", "search on google python tutorials", "tell me jokes", "bye"

## Features
- Voice input and text-to-speech responses
- Google and web searches
- YouTube search and video playback
- Date and time information
- Wikipedia summaries
- Word meanings, synonyms and antonyms
- Jokes and other utility functions

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- PyWhatKit
- Wikipedia
- PyJokes
- PyDictionary

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies:

   `pip install -r requirements.txt`

4. Run the main Python file:

   `python main.py`

## Requirements
- Python
- Windows operating system
- Microphone and speakers for voice interaction
- Internet connection for online features
